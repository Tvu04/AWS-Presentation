Section 1

Amazon Elastic Block Store (EBS)

Amazon EBS lets you create individual storage volumes and attach them to an Amazon EC2 instance. It offers block-level storage, volumes are automatically replicated within their Availability Zone, and they can be backed up to Amazon S3 through snapshots.

Snapshots

  • Point-in-time snapshots
  • Recreate a new volume at any time

Encryption

  • Encrypted Amazon EBS volumes
  • No additional cost

Elasticity

  • Increase capacity
  • Change to different types

Common uses

  • Boot volumes and storage for Amazon EC2 instances
  • Data storage with a file system
  • Database hosts
  • Enterprise applications

Boot volume?YesYesNoNo

Only SSD volumes can be boot volumes. Provisioned IOPS gives the highest performance, but General Purpose is usually enough.

Pricing

Volumes and IOPS

  • Volumes persist independently from the instance and are charged by the amount provisioned per month.
  • General Purpose SSD: GB provisioned per month until storage is released.
  • Magnetic: number of requests to the volume.
  • Provisioned IOPS SSD: IOPS provisioned, times the percentage of days provisioned that month.

Snapshots and data transfer

  • Snapshots stored in Amazon S3 cost per GB-month of data stored.
  • Inbound data transfer is free.
  • Outbound data transfer across Regions incurs charges.

Key takeaways
  • Persistent and customizable block storage for Amazon EC2
  • HDD and SSD types, replicated in the same Availability Zone
  • Easy and transparent encryption, elastic volumes, backups through snapshots
Section 2

Amazon Simple Storage Service (S3)

A fully managed cloud storage service. Data is stored as objects in buckets, you get granular access control on both, and you pay only for what you use.

11 9sDesigned durability (99.999999999%)
5 TBMaximum size of a single object
UnlimitedVirtually unlimited total storage

Storage classes

ClassDesigned for
S3 StandardFrequently accessed data. 11 9s durability, four 9s availability.
S3 Intelligent-TieringData with unknown or changing access patterns.
S3 Standard-IAInfrequently accessed data. 11 9s durability, three 9s availability.
S3 One Zone-IAInfrequently accessed data kept in a single Availability Zone.
S3 GlacierLow-cost archiving with retrieval in minutes to hours.
S3 Glacier Deep ArchiveThe lowest-cost class for long-term retention.

Access it anywhere

  • AWS Management Console
  • AWS Command Line Interface
  • SDKs

Common use cases

  • Storing application assets
  • Static web hosting
  • Backup and disaster recovery
  • Staging area for big data

Common scenarios

  • Backup and storage
  • Application hosting
  • Media hosting
  • Software delivery

Pricing

You pay for

  • GBs stored per month, based on storage class and the number and size of objects
  • Transfer OUT to other Regions
  • PUT, COPY, POST, LIST, and GET requests (GET has a different rate)

You don't pay for

  • Transfers IN to Amazon S3
  • Transfers OUT to Amazon CloudFront or Amazon EC2 in the same Region
Key takeaways
  • Fully managed, virtually unlimited object storage
  • Pay only for what you use
  • Accessible any time, from anywhere, through a URL
  • Rich security controls
Section 3

Amazon Elastic File System (EFS)

File storage in the AWS Cloud: a petabyte-scale, low-latency, shared file system with elastic capacity. It supports NFS versions 4.0 and 4.1 and works with all Linux-based AMIs for Amazon EC2.

Works well for

  • Big data and analytics
  • Media processing workflows
  • Content management and web serving
  • Home directories

Implementation

  1. Create your Amazon EC2 resources and launch your instance.
  2. Create your Amazon EFS file system.
  3. Create mount targets in the appropriate subnets.
  4. Connect your EC2 instances to the mount targets.
  5. Verify the resources and protection of your AWS account.

Resources

File system

  • Has one or more mount targets
  • Tags: key-value pairs

Mount target

  • Created in a VPC subnet
  • One per Availability Zone
  • Must be in the same VPC

Needs

  • Subnet ID
  • Security groups
Key takeaways
  • File storage over a network, fully managed
  • Accessible from the console, an API, or the CLI
  • Scales up or down as files are added or removed; you pay for what you use
Section 4

Amazon S3 Glacier

A data archiving service designed for security, durability, and extremely low cost. Pricing is based on Region, and it works well for long-term archiving and backup.

Highlights

  • Designed for 11 9s of durability
  • Encrypts data in transit (SSL/TLS) and at rest
  • Vault Lock enforces compliance through a policy
  • Lifecycle rules can archive Amazon S3 content to S3 Glacier

Use cases

  • Media asset archiving
  • Healthcare information archiving
  • Regulatory and compliance archiving
  • Scientific data archiving
  • Digital preservation
  • Magnetic tape replacement

How to use it

  • RESTful web services
  • Java or .NET SDKs
  • Amazon S3 with lifecycle policies

Security

  • Control access with IAM
  • Data encrypted with AES-256
  • S3 Glacier manages your keys for you
