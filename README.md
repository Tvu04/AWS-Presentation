# AWS-Presentation

Speaker script website for **AWS Academy Cloud Foundations, Module 7: Storage**, Sections 1 and 2 (Amazon EBS and Amazon S3, slides 4–35).

## View the website

- **GitHub Pages:** https://tvu04.github.io/AWS-Presentation/
- **Claude artifact:** https://claude.ai/artifact/KKZuULqTzPaVNS72Dy9cyy

You can also download `index.html` and open it in any browser.

## Turn on GitHub Pages

1. Go to **Settings → Pages** in this repo.
2. Under **Source**, choose **Deploy from a branch**.
3. Pick branch `main` and folder `/ (root)`, then click **Save**.
4. After a minute or two, the site is live at the GitHub Pages link above.
